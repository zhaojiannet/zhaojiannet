## 关于我

- 2004 年，因为QQ账号被盗，对网络安全产生了浓厚的兴趣，开始废寝忘食地自学
- 2005 年，我的第一个网站上线，迈出了IT技术之路的第一步
- 2009 年，开始写博客，从一个懵懂的佛系IT少年一路走来，期间断断续续，折腾、学习过程中遇到的问题，就顺手记录下来
- 希望能帮助遇到同样问题的朋友，也欢迎分享给更多需要的人。

> 保持热爱，勇往直前
